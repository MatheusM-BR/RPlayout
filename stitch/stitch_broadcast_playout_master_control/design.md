Design Style & Tokens for RPlayout (Broadcast TV Master Control System):
- Theme: Ultra-Dark High-Contrast Broadcast Studio theme (optimized for low-light TV control rooms and glare-heavy field monitors).
- Color Palette:
  * Background: Deep Void Navy/Black (#05070E), Surface Cards (#111827 / #121A2B), Card Borders (#28354E / #5570AB).
  * On-Air / Active State: High-voltage Crimson Red (#FF3B30 / #FF5F5F) with subtle glowing indicators.
  * Next / Armed / Cued State: Vivid Amber/Gold (#FF9500 / #FFB340).
  * System OK / Ready: Broadcast Emerald Green (#34C759 / #3DDBA0).
  * Accent / Focus: Vivid Ice Blue (#3B82F6 / #5B9BFF).
- Typography:
  * Headers and Labels: Clean, modern Sans-Serif or Condensed (Inter / Barlow Condensed), uppercase badges.
  * Timecode, Countdown, Durations and Metrics: Monospace font (IBM Plex Mono / JetBrains Mono) with tabular numbers (tnum) for frame-accurate stability.
- Density: High information density, zero wasted space, crisp 1px borders, subtle glassmorphism/inset panels, WCAG AAA contrast ratio.
